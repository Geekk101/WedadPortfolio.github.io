# Wedad Jarayseh – Portfolio

Personal portfolio site: SAP Business One integration, data/reporting and AI research.

Single static page (`index.html`), no build step.

## Run locally
Open `index.html` in a browser.

## Publish with GitHub Pages
1. Repo **Settings → Pages**
2. Source: **Deploy from a branch**, branch `main`, folder `/ (root)`
3. Save. The site goes live at `https://<your-username>.github.io/<repo-name>/`

## Update content
Edit `index.html` (experience, projects and contact details are plain HTML).
